Trust before speed

A faster answer is only useful when it leaves evidence.

The agent result should make review cheaper, not optional. A reviewer needs to see what went in, what checks ran, what came out, and the final human decision.

  1. Input The task request, relevant files, ticket fields, or public source links.
  2. Checks run Commands, comparisons, test results, or inspection steps used to catch mistakes.
  3. Result The summary, patch, classification, or packaged proof the agent produced.
  4. Reviewer decision Approved, revised, rejected, or escalated with a short reason.

Evidence needed for this task

What the reviewer should ask for.

  • A small ticket sample with private details removed.
  • The routing labels or answer categories the agent used.
  • A pass over edge cases where the draft could be wrong.
  • The reviewer decision for each sampled result.
