Privacy boundary

This decision map links only to public pages, public GitHub repositories, and public publisher records already used by the site. It does not publish private notes, credentials, employer-sensitive implementation details, raw run logs, or unpublished runtime data.

  • Public repos can prove code shape, examples, tests, and documentation.
  • Public pages can prove the narrative, diagrams, and privacy-safe operating model.
  • Private production context stays private unless it has been deliberately sanitized into a public artifact.
